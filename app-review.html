Cyberdeck App Review

A deep-dive into Dear Diary's features, style & a roadmap for what's next ✨

📓 What Cyberdeck Does
✍️

Journal Entries

Create, edit, and delete diary entries. Each entry has a title, free-form content, a date stamp, and persists automatically to localStorage.

😊

Mood Tracking

Choose from 8 mood emojis (loved, happy, excited, calm, thoughtful, sad, frustrated, tired) to tag the emotional tone of each entry.

🎨

Card Colors

8 pastel card backgrounds — pink, purple, blue, teal, mint, yellow, orange, green — let each entry have its own personality.

⭐

Stickers

Decorate entries with stickers from 6 categories: Hearts, Stars, Flowers, Fun, Treats, and Vibes. Drag them from the picker directly onto the card editor.

🖱️

Drag & Drop

Reorder journal cards by dragging. Stickers can also be dragged from the picker into the editor drop zone using @dnd-kit.

🌈

5 Themes

Bubblegum, Rose Gold, Lavender, Peach, and Midnight — each with a full set of CSS custom properties that cascade across the entire UI.

H
⌨️ Full keyboard navigation & focus management
Accessibility UX
▾

Currently the app is mouse/touch-first. Screen reader users and keyboard-only users face barriers in the modal, sticker picker tabs, and drag-and-drop interactions.

  • Add aria-label, role, and aria-expanded to all interactive elements
  • Trap focus inside the modal when it's open; restore focus on close
  • Provide a keyboard alternative to drag-and-drop for entry reordering (↑/↓ arrow keys)
  • Add visible :focus-visible rings (not just :focus) styled to the theme color
  • Announce new entries to screen readers with an ARIA live region
Effort: Medium (2–3 days) Impact: High

🔍 Search & filter entries
Feature
▾

As the diary fills up, there's no way to find a specific entry or filter by mood. A search bar and mood/date filters would dramatically improve usability over time.

  • Add a real-time text search bar that filters entries by title and content
  • Add a mood-filter dropdown (show only "😊 Happy" entries, etc.)
  • Add a date range picker or "this week / this month" quick filters
  • Highlight search matches within the card content preview
Effort: Small–Medium (1–2 days) Impact: High

H
📱 Mobile-first modal & touch UX overhaul
Mobile UX
▾

The modal editor fills the viewport on small screens but doesn't use native mobile patterns. The sticker picker tabs are hard to tap and the drag-to-reorder is awkward on touch.

  • Refactor the modal to a bottom sheet on mobile (slides up from the bottom)
  • Increase tap target sizes for sticker tabs to at least 44×44px
  • Add long-press to enter reorder mode on mobile instead of immediate drag
  • Add haptic feedback on sticker drop (navigator.vibrate)
  • Test on real iOS/Android devices, not just Chrome DevTools emulation
Effort: Medium (2–4 days) Impact: High for mobile users

Feature Tech
▾

localStorage is cleared when the browser is cleared or a different device is used. Offering a JSON export/import and optionally a backend sync option protects user data.

M
⚡ Performance: virtualised list & memoisation
Performance Tech
▾

With dozens of entries the card grid re-renders entirely on every state change. This is fine now but will degrade with heavy use.

  • Wrap JournalCard in React.memo to skip unnecessary re-renders
  • Memoize filtered/sorted entry list with useMemo
  • Consider @tanstack/virtual if entry count grows beyond ~200
  • Add a useDebounce around the localStorage write (already partially done)
Effort: Small (half–1 day) Impact: Future-proofing
0 votes
L
🔒 PIN / password lock screen
Feature UX
▾

A diary app without any privacy protection is a common concern. Even a simple PIN lock on open would be a meaningful privacy improvement (data stays in localStorage — the lock is just a gate).

  • Add an optional 4–6 digit PIN setup in settings
  • Show a PIN entry screen on app load if a PIN is configured
  • Use crypto.subtle to hash the PIN before storing it
  • Add a "forgot PIN" that clears all data (with warning)
Effort: Small–Medium (1–2 days) Impact: High for trust/privacy

Tech Accessibility

  • Add a GitHub Actions CI pipeline to run tests on every push
Effort: Medium (2–3 days setup) Impact: Long-term quality
